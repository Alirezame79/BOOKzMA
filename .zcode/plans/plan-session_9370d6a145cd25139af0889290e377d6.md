# N-04: حذف کامل حساب کاربر — اجرا روی برنچ جدا

**قاعدهٔ مالک:** قبل از هر تغییری، از روی main برنچ جدید `feat/account-deletion` ساخته می‌شه و همهٔ کار روی همون برنچ انجام می‌شه؛ هیچ‌وقت روی main کار نمی‌شه. بدون commit/push مگر با اجازهٔ صریح.

## رفتار از دید کاربر (فلوی ۴ گامی، ۳ روش تأیید مختلف)

1. **گام ۱ — دکمهٔ «🗑 حذف حساب» در پروفایل:** پیام هشدار: همه‌چیز (استریک، فریزها، لاگ مطالعه، یادآورها) برای همیشه پاک می‌شه، برگشتی نیست، داده تا انقضای بکاپ‌های قدیمی ممکنه بمونه (طبق docs/BACKUP.md). دکمه‌ها: «متوجه‌ام، ادامه» و «انصراف».
2. **گام ۲ — دکمه‌های گزینه‌ای:** «چرا می‌خوای حذف کنی؟» (استفاده نمی‌کنم / یادآورها اذیت می‌کنن / نگرانی حریم خصوصی / دلیل دیگه) + «انصراف». انتخاب در ستون reason جدول سنگ‌قبر ذخیره می‌شه.
3. **گام ۳ — تأیید تایپی (روش متفاوت):** کاربر باید دقیقاً «حذف» رو تایپ کنه (FSM جدید). اعداد فارسی/عربی پشتیبانی می‌شه؛ ورودی غلط = پیام خطا. «انصراف» همیشه کار می‌کنه.
4. **گام ۴ — تأیید نهایی دکمه‌ای:** «بله، همه‌چیز پاک شود» / «انصراف». با تأیید: تراکنش واحد = درج سنگ‌قبر + DELETE FROM users (همهٔ FKها CASCADE) → پیام خداحافظی.

## ثبت‌نام مجدد و API و ادمین

- کاربر حذف‌شده که دوباره پیام بده: MembershipMiddleware پیام «حسابت قبلاً حذف شده» + دکمهٔ «شروع دوباره» (account_restore) می‌ده → سنگ‌قبر پاک و شروع تازه. برای کاربر سنگ‌قبری، activity/mark_started ثبت نمی‌شه.
- API: `DELETE /api/v1/me` (204) با همون منطق مشترک؛ `_load_user` برای کاربر سنگ‌قبری 401 می‌ده.
- ادمین: داشبورد دو KPI جدید: «حساب حذف‌شده» (کل) و «حذف ۷ روز اخیر».
