# نقشهٔ راه BOOKzMA

اولویت فعلی: کیفیت، امنیت، سرعت و پایداری ربات و API موجود. وضعیت «ایده» اجازهٔ پیاده‌سازی نیست؛ برای شروع هر مورد، اول spec در `docs/specs/` بنویس و تأیید مالک را بگیر.

وضعیت‌ها: `ساخته‌شده`، `در حال کار`، `برنامه‌ریزی‌شده`، `ایده`، `کنار گذاشته`.

## چطور ایدهٔ جدید اضافه کنیم

یک شناسهٔ یکتا و وضعیت `ایده` ثبت کن و مزایا، معایب، وابستگی‌ها و سؤال‌های باز را بنویس. اگر ارزشمند شد، spec بساز و پس از تأیید مالک وضعیت را به `برنامه‌ریزی‌شده` تغییر بده. اگر رد شد، ردیف را حذف نکن؛ وضعیت را `کنار گذاشته` کن و دلیل را ثبت کن. هیچ مورد roadmap به‌تنهایی مجوز نوشتن کد نیست.
